# HAR · Portafolio de Hagen Aguilar Roldán

Landing de una página que reúne el CV y el portafolio de **Hagen Aguilar Roldán**, diseñador gráfico y digital en formación. Presenta el perfil, cuatro proyectos (editorial, empaque, fotografía y animación), experiencia, educación, habilidades y contacto.

El sitio está construido con HTML, CSS y JavaScript sin dependencias externas. El contenido proviene de `CV.md` y el diseño se deriva de los tokens de `DESIGN.md`. Incluye índice navegable, galería de fotografía, reproductor de vídeo, diseño adaptable a móvil, tableta y escritorio, y criterios de accesibilidad: contraste AA, foco visible y navegación completa por teclado.
